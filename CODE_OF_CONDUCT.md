# Code of Conduct

UnCorrupt follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## TL;DR

- Be respectful. Critique the code, not the person.
- Assume good faith. People often have context you do not.
- No harassment, no discrimination, no doxxing. Reports of these end participation.
- Disagreements are fine; abuse is not.

## Scope

This applies to anywhere the project is represented: issues, pull requests, discussions, the HuggingFace Space, email exchanges about the project, and any in-person events where someone is participating as a contributor.

## Reporting

If someone is making the project worse to be part of, open a private GitHub Security Advisory at https://github.com/shitcoinsherpa/UnCorrupt/security/advisories/new and we will handle it confidentially. We respond within 72 hours.

The full text of the Contributor Covenant 2.1 is at https://www.contributor-covenant.org/version/2/1/code_of_conduct/ and applies in full.
